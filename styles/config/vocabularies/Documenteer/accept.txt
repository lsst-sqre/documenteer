# --- RST syntax / code-identifier artifacts ---------------------------------
# Snake_case identifiers (API function names, config keys) read as prose by
# Vale's spell checker; accept any lowercase snake_case token.
[a-z][a-z0-9]*(_[a-z0-9]+)+
# Trailing-underscore RST reference names (e.g. `Sphinx_`, `uv_`).
[A-Za-z][A-Za-z0-9_]*_
# Vale's dictionary has no possessives, so "else's" and "commit's" are
# otherwise flagged even though the base word is fine.
[A-Za-z]+'s
