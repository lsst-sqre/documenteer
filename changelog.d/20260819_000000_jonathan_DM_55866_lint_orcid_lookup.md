### New features

- `documenteer technote lint` now resolves an author's suggested `internal_id` by ORCID first. When a `technote.toml` author entry declares an `orcid`, the linter asks the Rubin author database which author holds exactly that ORCID before falling back to the fuzzy name search. ORCID is globally unique and author-supplied, so the exact lookup suggests an ID in cases the name search cannot — notably when the technote and the author database spell the name differently, where the name search returns several equally-good matches and previously suggested nothing. A miss, a malformed ORCID, or an unreachable database still falls through to the name search, and any failure of either lookup silently leaves the finding's plain message; a suggestion never changes whether the command passes or fails.
