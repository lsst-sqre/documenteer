### New features

- `documenteer technote lint` now cross-checks a technote's DOI against DataCite with a new **TN105** rule: it reads the metadata registered for the DOI from DataCite's public API and warns when the registered title or author list has drifted from `technote.toml`. Both comparisons are deliberately tolerant — case and whitespace in the title, and case, punctuation, accents, and ordering in the author set — because the registered metadata is not something a technote author always controls, so a false positive is worse than a miss. TN105 uses the network, as the author checks (TN101–TN103) do, but unlike them it degrades to silence rather than reporting an unreachable service: a technote with no DOI, a DOI that is not a DOI (which `technote.toml` parsing rejects, so it is TN001's finding), a DOI DataCite does not know yet (404), and a DataCite that cannot be reached at all — no network, a timeout, an outage — each leave the run reporting nothing, so working offline is indistinguishable from working online. See [TN105](https://documenteer.lsst.io/technotes/lint/tn105.html).
