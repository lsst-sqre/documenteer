### Bug fixes

- The GitHub link in the user guide header now uses the round FontAwesome GitHub mark (`fa-github`) instead of the square one (`fa-square-github`). The square mark fills its whole glyph box and rendered oversized next to the theme switcher and the theme's other header icons; the original 2022 configuration chose the square variant and the pydata-sphinx-theme 0.19 / FontAwesome 7 upgrade carried it forward under its renamed class.
