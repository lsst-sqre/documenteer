### New features

- `documenteer technote lint` now checks a technote's citation metadata with two new offline rules. **TN104** reports a `[technote] doi` that is not syntactically a DOI, validating it with the same normalizer every other DOI surface in Documenteer uses, so a DOI that passes the linter is one the citation composer and the `CITATION.cff` generator accept; a technote that declares no DOI is not flagged, since a DOI is minted when the technote is released. **TN106** reports a `CITATION.cff` that no longer matches what `technote.toml` generates, using the same comparison `documenteer technote sync-cff --check` runs, so the linter and that CI gate can never disagree; a repository with no `CITATION.cff` is silent, because adopting the file is opt-in. Both rules have landing pages under [the lint rule reference](https://documenteer.lsst.io/technotes/lint/).
