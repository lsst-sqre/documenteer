### New features

- The link-check builder now rechecks from the build's own vantage point the URLs the service couldn't verify from its own, and merges what it observes into that same build's report. Two of Ook's verdicts rest on evidence nobody actually obtained about the link: `blocked`, when its requests trip a site's bot-protection edge (typically a Cloudflare `403`) in a way it can't distinguish from a URL refusing everyone, and `broken` with no HTTP status code, when it got no response at all — a TLS chain it couldn't build, a dropped connection, a name it couldn't resolve — which fails the build on a verdict that says more about the service's network than about the link. A documentation build usually runs somewhere else entirely, with its own trust store and its own route, so it can often settle what the service couldn't: exactly those URLs are rechecked, sequentially and with a politeness delay, sending the same request Sphinx's built-in `linkcheck` builder would send (its browser-prefixed `User-Agent` and `Accept` header, HEAD then a streamed GET, redirects captured). A `broken` verdict that does carry a status code is a definite answer from the server itself and is never rechecked. A URL the build resolves is reported `ok` — or `redirected`, if it works only through a permanent redirect — and its caveat or unreproducible failure clears; a URL that answers the build with a definite failure is reported `broken` with the build's own evidence; a URL blocked from the build's vantage point too keeps its caveat and the service's evidence untouched, as does one that answers the build with nothing at all (a timeout or a dropped connection settles nothing — bot protection doesn't always answer with a status code — so only a failure the server itself answered with is allowed to turn a caveat into a build failure), and a URL neither vantage point could reach stays `broken` and still fails the build, with a detail line recording that both looked. The `linkcheck.json` artifact carries the merged view, with each result the build rechecked for itself flagged `locally_rechecked`. Set `[sphinx.linkcheck] recheck_unverified = false` in `documenteer.toml` (or `documenteer_linkcheck_recheck_unverified = False` in a technote's `conf.py`) to skip the recheck and report the service's verdict as-is.
