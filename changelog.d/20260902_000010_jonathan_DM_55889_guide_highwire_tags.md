### New features

- A user guide's DOI landing-page metadata now carries the full set of Highwire `<meta>` tags, not just `citation_doi`. Every page describes the `self` citation with `citation_title`, a `citation_author` per author (family name first) followed by that author's `citation_author_institution` and `citation_author_orcid`, `citation_publication_date` in one of the two forms Google Scholar's inclusion guidelines document (`2025/06/30` for an entry dated to the day, `2025` for one dated to the year or the month), `citation_doi`, `citation_publisher`, and `citation_fulltext_html_url`, alongside the Dublin Core `DC.identifier` as before. Highwire tags are what Google Scholar's inclusion guidelines specify and what Zotero's embedded-metadata translator reads, so a reader now gets a one-click "Save to Zotero" with the right title, creators, date, and DOI. A page claimed by a `[[project.citations]]` entry's `page` carries that entry's tags with the page's own URL; a page several entries claim emits none of them, since every tag is single-valued. A field the entry does not state emits no tag, and a site that marks no entry `self` emits none of them — it is no DOI's landing page. Every value is HTML-escaped.
