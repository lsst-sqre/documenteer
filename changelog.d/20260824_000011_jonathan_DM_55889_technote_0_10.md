### New features

- Documenteer's `technote` extra now requires [technote](https://technote.lsst.io) 0.10.0 or later. That release wires the `[technote] doi` field into the technote's citation metadata: a technote that declares a DOI emits a populated `citation_doi` Highwire tag, and the DOI reaches the Dublin Core and schema.org JSON-LD blocks in the page head — the machine-readable half of a DataCite landing page. Those two blocks themselves land on every technote, with or without a DOI; only `citation_doi` depends on having one. It also validates and normalizes `[technote] doi` when `technote.toml` is parsed, which means a DOI written as a bare identifier, a `https://doi.org/` URL, or with a `doi:` prefix all reach the rest of Documenteer in the same bare spelling, and a value that is not a DOI is reported by the `documenteer technote lint` schema-conformance rule (TN001), which names the `technote.doi` field and the value it rejected.
