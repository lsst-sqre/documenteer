### Other changes

- A user guide's site-wide schema.org JSON-LD block is now a set of *relations* to the site's `self` citation rather than a copy of every `[[project.citations]]` record. An entry that names a `page` is a part of the site's work: the site-wide block names it under `hasPart` by reference alone (schema.org type, DOI, and title), and the page it claims carries the full record plus an `isPartOf` reference back. An entry with no `page` is a work the site cites, and reaches the block in full only when `in_footer` is true — so `in_footer` now governs the site-wide metadata as well as the footer. An entry that is neither a part nor shown in the footer no longer appears in the block, though a `citation-card` that names it still renders it. This keeps a data release's documentation from repeating its whole catalog of product DOIs on every page.
