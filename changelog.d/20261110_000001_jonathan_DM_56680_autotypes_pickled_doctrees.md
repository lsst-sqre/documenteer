### Bug fixes

- `documenteer.ext.autotypes` now degrades the enum members in an inherited field's `Annotated` metadata to plain text when a build reuses pickled doctrees. A model that inherits a field such as `phase: Annotated[ExecutionPhase, Field(examples=[ExecutionPhase.PENDING])]` renders that annotation from its source text, and the extension recognized the resulting `ExecutionPhase.PENDING` reference only through a copy of the source annotation that autodoc leaves on the class while reading the sources. A second build over the same doctree directory, such as a linkcheck run after an HTML build, never runs autodoc, so it warned `py:class reference target not found` under nitpicky mode. The extension now reads the annotation source itself, and imports the documented modules before scanning them for type variables and aliases, so its results no longer depend on whether the build read the sources.
