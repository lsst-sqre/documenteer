### New features

- New `citation-card` directive for user guides, which renders one of the site's `[[project.citations]]` entries as a card: the entry's label, the full bibliographic citation with its DOI written as a resolvable `https://doi.org/` hyperlink, and the entry's note. With no argument the card renders the entry marked `self = true` — the work whose DOI landing page the site is — and an optional argument selects another entry by its `label`, so a page can cite both a data release and the paper that describes it. A card is what a "Citing this site" page needs, and it replaces the hand-built citation blocks that Rubin data release sites have been carrying. The citation is read from the `html_context` the guide preset composes, so a card, the page `<head>` metadata, and the site footer can never disagree about what the site's citation says.

- A `citation-card` that names a label no citation carries, or that has no argument on a site where no entry is marked `self = true`, renders nothing and warns rather than failing the build, naming the labels the site does declare. The warning's subtype is `documenteer.citation_card`, so a site that knowingly carries an unresolved card can add it to `suppress_warnings` and keep its warnings-as-errors build green.
