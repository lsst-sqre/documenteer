### New features

- New `documenteer technote sync-cff` command generates a technote repository's `CITATION.cff` from `technote.toml`, so GitHub's "Cite this repository" button offers a proper technote citation. The Citation File Format allows only `software` or `dataset` as a file's top-level `type`, so the technote itself is written as the file's `preferred-citation` — a `report` reference carrying the DOI, the authors with their ORCIDs and affiliations, the publishing institution, the technote's handle as `number`, the release date, and the canonical URL. `technote.toml` stays canonical: the file is regenerated from scratch on every run and says so in a header comment. Generation is deterministic and offline, so re-running on an up-to-date file changes nothing, and `--check` is a content comparison suitable for CI — it exits non-zero only when `CITATION.cff` exists and is stale, since a repository with no `CITATION.cff` has simply not adopted it. A technote without a DOI still generates a valid file. See the new *Generating a CITATION.cff* page in the technote guide.

- Documenteer now ships a `.pre-commit-hooks.yaml` at its repository root exposing a `technote-sync-cff` [pre-commit](https://pre-commit.com) hook, so a technote repository can wire the sync into pre-commit like any other hook and keep `CITATION.cff` in the same commit as the `technote.toml` change that implies it.
