### Other changes

- A user guide's `self` citation now appears in the footer by default even when the site marks a *different* `[[project.citations]]` entry `preferred`. `in_footer` previously defaulted to true for the preferred entry alone, so a site that is one DOI's landing page while asking readers to cite another work silently dropped its own citation from the footer — and the footer is what makes every page of such a site a DataCite-conformant landing page, which asks a landing page to display the citation of the DOI it is the landing page of. Both entries now default in, in array order, so the guidance holds without the author opting back in; a site that wants one footer citation writes `in_footer = false` on the other. Nothing changes for a site whose `self` entry is also its preferred citation, for a site that marks only one of the two, or for one that sets `in_footer` explicitly.
