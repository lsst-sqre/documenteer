### New features

- User guides can now declare their citations in a new `[[project.citations]]` array of tables in `documenteer.toml`, the configuration behind making a Documenteer-built site a proper DOI landing page. Each entry pairs the bibliographic record of a cited work — `doi` (accepted bare, as a `https://doi.org/` URL, or with a `doi:` prefix, and rejected at load time if it is not a DOI), `title`, `authors`, `publisher`, and `date` — with the presentation fields that say how the site displays it: `label` distinguishes one citation from another, `self` marks the DOI whose landing page this site is (at most one entry, validated), `in_footer` puts a citation in the site footer (default true for the `self` entry, opt-in for the rest, in array order), and `note` carries free text about when to use the citation. Authors are written as either organizations (`name`, `ror`) or people (`family_name`, `given_name`, `orcid`, `affiliation`), so a dataset credited to "Vera C. Rubin Observatory" cites correctly.

- A `[[project.citations]]` entry can set `cff` to the path of a `CITATION.cff` file, relative to `documenteer.toml` — typically `"../CITATION.cff"` — and take its bibliographic fields from the file a repository already maintains for GitHub's "Cite this repository" button instead of restating them. Any field set alongside `cff` overrides the file's value, so one field can be corrected without abandoning the file; the presentation fields are always `documenteer.toml`'s alone. A `cff` path that names no file, or a file that cannot be read as a citation, fails the build with an error naming the resolved path and the offending entry.

- The guide configuration preset resolves the declared citations and publishes them into Sphinx's `html_context` as `documenteer_citations` (every citation, in array order) and `documenteer_self_citation`. Each is a plain mapping carrying the citation's fields along with its ready-made `plain_text` and `bibtex` renderings and the DOI as a resolvable `doi_url`, so the surfaces that display a citation only read the context and never recompose it. A guide that declares no citations sets neither key and is unchanged.
