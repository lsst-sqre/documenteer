### Bug fixes

- A `[[project.citations]]` entry that reads the top-level record of a `CITATION.cff` file — `cff_preferred = false`, or a file that declares no `preferred-citation` — is now typed as software when the file declares no `type` of its own. CFF restricts that key to `software` or `dataset`, makes it optional, and defines its default as `software`, so nearly every real file (Zenodo- and GitHub-generated ones, and `lsst/daf_butler`'s) leaves it out. Such a record previously composed as an untyped work — BibTeX `@misc` and a schema.org `CreativeWork` — where it now composes as `@software` and `SoftwareSourceCode`, with no `type` to write in `documenteer.toml`. A `preferred-citation` that declares no type still leaves the entry untyped, since CFF gives a reference no default and dozens of types to choose between, and an inline `type` still overrides whatever the file supplies.
