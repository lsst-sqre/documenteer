### Other changes

- The user-guide citation documentation now covers a package that has never been deposited for a DOI, which was the one shape of site the worked examples never showed. A new [Software that has never been deposited](https://documenteer.lsst.io/guides/citations.html#software-that-has-never-been-deposited) section gives the complete `documenteer.toml` for a citation located by its repository `url`, and says why such an entry is marked `preferred = true` rather than `self = true`: `self` is the claim that this site is a DOI's registered landing page, so it needs a DOI to be the landing page of. The `url` field reference now sets `preferred = true` in its own example and links to that section — copied verbatim, the old example rendered no card and no footer citation, because an entry that is neither `self` nor `preferred` reaches no surface on its own.

- Four corrections to the same reference. The Highwire tag table no longer describes `citation_fulltext_html_url` as "the page's own URL": it is the site's root URL for the `self` entry, which is the URL that DOI is registered against, and the claimed page's own URL (with the claim's fragment) only for an entry that sets `page`. The `type` reference now says that a work that is none of the listed kinds — an instrument or a facility, such as LSSTCam — is `"other"`, and how that differs from leaving `type` unset. The `[[project.citations]]` reference now tells a site that declares citations to set `base_url` explicitly, because every URL in the landing-page metadata is composed from it and the `[project.python]` fallback is whatever `pyproject.toml` names as its `Homepage`. And the worked examples now write the publisher and author name Rubin's real DataCite records use, `NSF-DOE Vera C. Rubin Observatory`, since examples are what people copy.
