### New features

- A user guide's citation surfaces now offer the citation's BibTeX entry. Both the `citation-card` directive and the footer citations carry a collapsed `BibTeX` disclosure holding the entry composed from the site's `[[project.citations]]` metadata, with a `Copy BibTeX` button that puts it on the clipboard — the affordance GitHub's "Cite this repository", Zenodo, and ADS offer. Readers paste the entry into a `.bib` file they already keep, so a guide generates no `.bib` files of its own and there is nothing to download; the entry is in the page rather than in a script, so it can always be selected and copied by hand. A browser that gives the page no clipboard access has the button removed and keeps the entry, and a non-HTML builder renders the entry as a plain literal block. The script that wires the buttons up is shipped only by a site that declares citations, so a guide without them is unchanged.
