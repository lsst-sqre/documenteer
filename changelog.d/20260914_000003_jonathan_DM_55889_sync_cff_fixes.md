### Bug fixes

- `documenteer technote sync-cff --check` no longer prints a warning on a run that finds `CITATION.cff` already up to date. The warning about an undeclared `date_updated` used to be echoed before the comparison was made, so the `technote-lint` tox environment — and therefore `make lint` — printed `Warning: …` to stderr on every *passing* run of any technote without a `date_updated`, which is most of them. The warnings are now reported only by a run that writes the file or reports it stale; a clean `--check` prints nothing to stderr. Its wording changed too: the technote's own citation is dated by the commit that published it, so the warning now says that this *file* carries no release date, rather than offering to "date the citation".

- `documenteer technote sync-cff` now writes `url:` — at both the top level and in `preferred-citation` — in the same normalized form the technote's own pages publish. It was read verbatim from `technote.toml`, so a technote declaring `canonical_url = "https://sqr-112.lsst.io"` was cited at `https://sqr-112.lsst.io` in `CITATION.cff` while the sidebar BibTeX, the article-end link, `DC.identifier`, and the JSON-LD on the built page all carried `https://sqr-112.lsst.io/`. A `CITATION.cff` generated before this change reports the added slash as a one-time `--check` staleness; re-run `documenteer technote sync-cff` to regenerate it.
