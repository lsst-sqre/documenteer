### New features

- A user guide can now link one of its `[[project.citations]]` entries inline with a new `doi` role: ``:doi:`Object catalog``` renders the entry's DOI as a link whose text is the resolvable `https://doi.org/` URL, and ``:doi:`the DP2 paper <Paper>``` puts custom text on the same link. The role names an entry by its `label`, matched exactly the way the `citation-card` directive's argument is, and renders a single external hyperlink, so it composes in a sentence, a list item, a table cell, a MyST `{doi}` role, and the body of a `replace` substitution definition — the uses a block-level card cannot serve, such as the DOI bullet of a data product's "Access" list. A label no entry carries, and an entry that declares no DOI, warn under the existing `documenteer.citation_card` subtype and render unlinked text rather than failing the build; an entry located by `url` alone is not linked, because in the role's default spelling the link's text *is* the DOI.
