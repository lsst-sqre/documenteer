### New features

- The user-guide theme now gathers page-improvement links in a "Help improve this page" box at the bottom of each page, below the previous/next page links. The box contains the "Edit on GitHub" link (relocated from its default position in the right sidebar) and the Git-derived "last modified" timestamp (relocated from the article footer). This layout follows the article-footer pattern used by MDN Web Docs and provides a home for future page-feedback features. Individual pages can suppress the box with the `hide_content_footer` file-wide metadata field (a `:hide_content_footer:` field at the top of a reStructuredText file, or `hide_content_footer: true` in MyST front matter). In printed output the interactive box is replaced by a print-only provenance footer at the end of the article carrying the "last modified" timestamp and the page's canonical URL.
