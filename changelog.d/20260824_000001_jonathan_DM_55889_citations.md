### New features

- New `documenteer.citations` module: the shared implementation of bibliographic citations for Documenteer-built sites. A `Citation` value object holds the DataCite mandatory metadata (creators, title, publisher, publication year, identifier) plus a landing-page URL and a series number, and composes it either as a plain-text reference (`to_plain_text()`) or as a BibTeX entry (`to_bibtex()`, as `@misc` for datasets and websites or `@techreport` for technotes). Authors are either people or organizations, so a dataset credited to "Vera C. Rubin Observatory" cites correctly — including the braces that stop BibTeX from abbreviating a corporate name, or the name of a person credited by family name alone, such as Rubin's Survey Cadence Optimization Committee. Composition is local and deterministic: no network access, a stable citation key, and a fixed field order, so a rebuild never churns the output. The module also provides `normalize_doi()` and `doi_url()`, which accept a DOI written bare, as a `https://doi.org/` URL, or with a `doi:` prefix, and reject anything else with a `ValueError` — matching the `technote` package's DOI semantics so that guides, technotes, and the technote linter all spell a DOI the same way.
