### Other changes

- The `documenteer.citation_date` warning no longer reports a `software` citation located by a `url` rather than by a DOI. Software released continuously has no publication event to date: the year of its first release is stable only because it never moves, the year of its current release churns every January, and neither says which code a reader ran — the `version` does, qualified by the date the reader accessed it. Reporting such an entry made `suppress_warnings = ["documenteer.citation_date"]` the end state of every package site, which also silenced the dated works its author did want to hear about. Software deposited for a DOI is still reported, since DataCite requires a publication year of every DOI and so the date exists to be written down, as is an entry reading a `CITATION.cff` file's `preferred-citation`, which names a work other than the repository the file describes.
