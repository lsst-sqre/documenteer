### Other changes

- Documenteer's own documentation now has advisory prose linting with [Vale](https://vale.sh) and the Google Developer Documentation Style Guide package, plus a small set of house rules and a project vocabulary. Run it locally with `nox -s vale` (optionally passing paths to lint a single page). On pull requests, CI posts Vale findings as non-blocking inline annotations on changed documentation lines, and the weekly periodic workflow uploads a whole-corpus report as an artifact. Vale never fails a build: it is not in the default nox sessions, has no prek hook, and is not a required status check. See the new *Editorial linting with Vale* page in the developer guide.
