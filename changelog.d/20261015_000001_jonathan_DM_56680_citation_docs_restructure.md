### Other changes

- The user-guide citations documentation is now a section rather than a single page. An overview at [guides/citations/](https://documenteer.lsst.io/guides/citations/index.html) starts with how to declare a citation and where it is displayed, followed by recipes for specific kinds of site (a DOI landing page, landing pages inside the site, software cited from a `CITATION.cff` file, software that has never been deposited, and sites with a large API reference) and a page per display surface (citation cards, inline DOI links, the footer, and machine-readable metadata), with every build warning gathered on one troubleshooting page. The old single-page URL redirects to the overview. Documenteer's own documentation now declares real citations — a `CITATION.cff` at the repository root and the ADASS XXXIII paper on documentation engineering at Rubin — so the cards, inline DOI links, and footer citation shown in these pages are rendered live from the site's own configuration rather than described in text.
