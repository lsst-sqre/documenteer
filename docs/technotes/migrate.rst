###############################
Migrate a legacy technote
###############################

:command:`documenteer technote migrate` is a deprecated alias for :command:`documenteer technote update`.
It converts a legacy :file:`metadata.yaml` technote exactly as it always did, takes the same options, and additionally refreshes a technote that has already been converted — so there is no reason to keep using the old name.
See :doc:`update`, which is where this page's content now lives.
