Object catalog
==============

The registered landing page of two DOIs, one per access path.

.. _object-butler:

Butler
------

An explicit target, which docutils propagates onto the section *after* the
anchor generated from the heading's text — so the anchor this DOI is
registered against is neither the section's first id nor the one the project's
table of contents records for it.

TAP
---

A heading with no explicit target, so the anchor generated from its text is
the only one it has.
